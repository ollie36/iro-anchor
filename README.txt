いろアンカー 完成候補版

収録:
- JIS Z 8102:2001 慣用色名 269色
- 269日一巡するまで日替わり色の重複なし

キャラクター:
- AniList検索
- 検索登録時は native 名 + full 名を保存
- 図鑑で日本語名/英語・ローマ字名を併記
- 手動画像登録時も日本語名と英語/ローマ字名を入力可能
- 登録後の画像差し替え可能
- 1色 = 1キャラクター

検索:
- 正式色名ではなく、赤髪・青髪・銀髪など検索向きの髪色カテゴリを使用

アップデート:
- IndexedDB名 iro-anchor-v3 / store pairs を維持。
- 同じWebサイト（同じorigin）でアプリ本体を更新する限り、登録データは原則そのまま残る。
- 設定からJSONバックアップの書き出し/読み込みが可能。
- 機種変更やブラウザデータ削除に備えて、ときどきバックアップ推奨。

Pixel:
完成版をWeb上の固定URLへ置き、PixelのChromeから「アプリをインストール」
または「ホーム画面に追加」する運用を想定。
以後は同じURLのファイルを更新すれば、PWA本体を更新できる。
